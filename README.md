# Arabic Sentiment Analysis with Explainable AI (XAI)

Sentiment classification of Arabic text into **negative**, **neutral**, and **positive**, comparing classic machine learning baselines against a fine-tuned Arabic transformer (MARBERT), with model explanations produced using LIME.

## Overview

This project trains and compares three models on an Arabic sentiment dataset:

- **Logistic Regression** (TF-IDF features)
- **Linear SVM** (TF-IDF features)
- **MARBERT** — a transformer pre-trained on Arabic, fine-tuned for sentiment classification

It also uses **LIME** (Local Interpretable Model-agnostic Explanations) to show which words drove each model's prediction, making the results interpretable rather than a black box.

> **Note:** Trained model files (`models/`, `.pkl`, `.safetensors`) are not stored in this repository because of their size. They are regenerated by running the training scripts below.

## Preprocessing

Arabic text is cleaned before training: links and mentions are removed, the hashtag symbol is stripped, Arabic letters are normalized (e.g. أ/إ/آ → ا, ى → ي), diacritics (tashkeel) are removed, and non-Arabic characters and extra whitespace are cleaned out.

## Setup

```bash
# 1. Clone the repository
git clone https://github.com/Noor235/arabic-sentiment-xai.git
cd arabic-sentiment-xai

# 2. (Recommended) create a virtual environment
python -m venv venv
source venv/bin/activate        # on Mac/Linux

# 3. Install dependencies
pip install -r requirements.txt
```

## Usage

Run from inside the `src/` folder.

```bash
# Train the baseline models (Logistic Regression + SVM)
python train_baseline.py

# Fine-tune MARBERT
python train_transformer.py

# Compare all models and save metrics, charts, confusion matrices
python evaluate_results.py

# Try predictions on random test samples
python predict.py

# Generate LIME explanations
python explain_lime.py
python explain_marbert_lime.py
```

## Results

Running `evaluate_results.py` produces, in the `results/` folder:

- `model_comparison_metrics.csv` — accuracy, precision, recall, F1 for each model
- `model_accuracy_comparison.png` — accuracy comparison bar chart
- confusion matrices for each model
- per-model classification reports

LIME explanations are saved as HTML files showing the words that most influenced a prediction.

## Models

| Model | Features | Notes |
|-------|----------|-------|
| Logistic Regression | TF-IDF (1–2 grams) | Fast, interpretable baseline |
| Linear SVM | TF-IDF (1–2 grams) | Strong linear baseline |
| MARBERT | Contextual embeddings | Arabic-specific transformer (UBC-NLP/MARBERT) |
